// 01 — Actions réalisées

Ce que j'ai
construit

☁

Infrastructure AWS (VPC + EC2)

Mise en place d'un réseau virtuel (VPC), configuration des groupes de sécurité et provisionnement des instances EC2 pour héberger la stack de monitoring.

AWS · EC2 · VPC
🐳

Stack Zabbix conteneurisée

Déploiement de la stack complète Zabbix — serveur, interface web, base de données MySQL — via Docker Compose pour garantir portabilité et isolation.

Docker · Docker Compose
🔌

Agents Linux & Windows

Installation et configuration des agents Zabbix sur instances Ubuntu et Windows Server pour collecter les métriques système en temps réel.

Zabbix Agent · SSH · WinRM
📊

Dashboards & Alertes

Création de tableaux de bord temps réel pour CPU, RAM, disque et réseau, avec configuration des triggers d'alerte pour la détection proactive des incidents.

Monitoring · Alerting · KPI
