Aperçu du
Projet

/01

SahaTech AI est un projet académique de pointe conçu pour simuler un workflow d'orientation clinique complet. Il orchestre plusieurs agents spécialisés pour recueillir les données patient, analyser les symptômes, et générer des recommandations structurées sous la supervision d'un médecin.

L'architecture repose sur LangGraph pour la gestion de l'état et du flux, FastAPI pour l'exposition des services, et Angular 17 pour une interface utilisateur moderne et réactive.

Points Clés :

  • Workflow Multi-Agents complexe
  • Interruption Human-in-the-Loop (Validation Médecin)
  • Intégration du Model Context Protocol (MCP)
  • Génération de rapports structurés avec export PDF
  • Conformité aux contraintes éthiques médicales

Le Chœur des
Agents

/03
01

Supervisor Agent

L'orchestrateur central. Il dirige le flux de données entre les agents en fonction de l'état partagé (MedicalState), assurant une transition fluide du diagnostic vers la revue humaine.

02

Diagnostic Agent

Interagit avec le patient via un outil dédié (ask_patient_question). Il pose exactement 5 questions ciblées pour construire une synthèse clinique et identifier les signes d'alerte.

03

Physician Review (HITL)

Le point critique du système. Le workflow s'interrompt pour permettre à un médecin réel de valider la synthèse, d'ajuster le score de gravité et de prescrire une conduite à tenir.

04

Report Agent

Assemble l'intégralité des données (symptômes, Q/R, revue médecin) dans un rapport professionnel bilingue, incluant les mentions légales obligatoires.

Éthique &
Conformité

/06

Ce système a été développé avec une attention stricte portée à l'éthique médicale. Il ne remplace en aucun cas une consultation médicale réelle. Toutes les sorties sont marquées comme "orientation clinique préliminaire" et la validation humaine est obligatoire pour finaliser le processus.
